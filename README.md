## 🎮 About The Game

**Handaconda** reinvents the classic arcade experience by integrating cutting-edge computer vision. Using **MediaPipe's Hand Tracking**, the game detects your index finger in real-time through your webcam, allowing you to guide the snake with natural movements. No keyboard, no mouse—just you and the game.

## ✨ Features

- **👆 Gesture Control**: Precise tracking of your index finger to steer the snake.
- **⚡ Instant Response**: Low-latency tracking for a smooth gaming experience.
- **🎨 Modern UI**: Cyberpunk-inspired aesthetics with Tailwind CSS.
- **🔊 Immersive Audio**: Sound effects for eating and game over states.
- **📱 Responsive**: Works on desktop and capable mobile devices.

## 🚀 How To Play

1.  **Allow Camera Access**: The game needs to see your hand!
2.  **Raise Your Hand**: Show your hand to the camera.
3.  **Point Your Finger**: Use your **Index Finger** to direct the snake.
4.  **Eat & Grow**: Guide the snake to the apples.
5.  **Avoid Crashes**: Don't hit the walls or your own tail!

## 🛠️ Installation & Setup

Clone the repository and get started in seconds.

```bash
# Clone the repo
git clone https://github.com/Imran-Ashiq/handaconda.git

# Enter the directory
cd handaconda

# Install dependencies
npm install

# Start the development server
npm run dev
```
